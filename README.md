# Lenny Growth Assistant

An AI product-growth advisor: a chat assistant that answers growth
questions grounded in a small curated corpus of growth frameworks, and
does deterministic CAC/LTV math when asked a quantitative question —
instead of guessing numbers.

See `docs/PRD.md`, `docs/design.md`, and `docs/architecture.md` for the
product reasoning, UX decisions, and technical design behind this.

## Prerequisites

- Python 3.11+
- PostgreSQL 14+ (local install, Docker, or a hosted instance like Supabase)
- One of: Ollama installed locally (free/local model path), or an Anthropic API key (cloud model path)
